# Фотографии работ

Галерея на сайте собирается автоматически из этой папки через `import.meta.glob`.
Достаточно положить сюда файлы — пересобирать ничего не нужно, Vite подхватит их сам.

## Что положить

8 фотографий, переданных клиентом. Рекомендуемые имена (порядок = порядок в галерее):

| Файл | Что на фото |
|---|---|
| `01-color-teal.jpg` | Цветное наращивание, бирюзовые кончики, оформленные брови |
| `02-classic-brows.jpg` | Классическое наращивание, натуральный эффект, укладка бровей |
| `03-color-green.jpg` | Цветное наращивание, зелёные кончики, широкие брови |
| `04-color-burgundy.jpg` | Цветное наращивание, бордовый цвет |
| `05-natural-mink.jpg` | Натуральная норка, тёплый коричневый тон |
| `06-volume-black.jpg` | Объёмное наращивание, глубокий чёрный |
| `07-brows-lamination.jpg` | Ламинирование бровей, натуральный объём ресниц |
| `08-portrait-makeup.jpg` | Портрет: макияж, стрелки, укладка |

## Требования к файлам

- Формат: `.jpg`, `.jpeg`, `.png` или `.webp`
- Пропорции: квадрат (1:1) — галерея рассчитана на квадратную сетку
- Размер: 1200×1200 px достаточно; больше — лишний вес страницы
- Вес: до 300 КБ на файл. Если исходники тяжелее — сжать перед загрузкой

## Подписи

Подписи к фото лежат в `src/components/Works.tsx` в массиве `CAPTIONS` и
сопоставляются с файлами по порядку сортировки имён. Поэтому имена и начинаются
с номера.
