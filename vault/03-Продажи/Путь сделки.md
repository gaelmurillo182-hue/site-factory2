Повод → Первое сообщение → Квалификация → Разбор или аудит → Демо на данных клиента →
Предложение → Договор и предоплата → Работа → Сдача с замером → Апгрейд или подписка

| Этап | Цель | Признак «дальше не идём» |
|---|---|---|
| Повод | зацепиться за конкретную боль | повода нет — сообщение не отправляем |
| Первое сообщение | получить ответ, не продать | нет ответа после двух касаний — в отложенные на 3 месяца |
| Квалификация | понять: деньги, боль, данные | нет измеримой метрики — предлагаем только аудит |
| Разбор или аудит | найти цифру «до» | не дают доступ к цифрам — не работаем |
| Демо | показать на его данных | не дают данные для демо — сигнал недоверия, разбираемся до сделки |
| Предложение | одна страница, одна цена, один срок | просят «подешевле» без сокращения объёма — торг, не работа |
| Договор | предоплата 50% | нет предоплаты — нет старта. Исключений не делаем |
| Сдача | замер «после» рядом с «до» | нет цифры «после» — проект не закрыт |
| Апгрейд | следующая ступень или подписка | предлагается не раньше чем через месяц после сдачи |
