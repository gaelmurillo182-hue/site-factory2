Что нужно от клиента для запуска проекта. Собирается на старте:
незакрытый пункт здесь — это срыв срока.

## Правила

- Доступы выдаются на отдельную учётную запись для подрядчика, не личную запись сотрудника.
- Пароли передаются через менеджер секретов или разовую ссылку, не в переписке.
- Права — минимально необходимые. Полный администратор запрашивается только при обосновании.
- На сдаче проекта — акт передачи доступов и отзыв наших учётных записей по желанию клиента.

## Типовой перечень

- [ ] CRM: учётная запись, права, доступ к API
- [ ] Телефония: доступ к записям, исходящая линия
- [ ] Мессенджеры: права администратора на бизнес-аккаунт
- [ ] Сайт: доступ для установки виджета
- [ ] Учётная система (1С и аналоги): метод обмена, тестовая база
- [ ] Система записи или МИС: API-доступ
- [ ] Почта: ящик или пересылка
- [ ] Аккаунты ИИ-сервисов: заводит клиент на себя, нам выдаёт ключ
- [ ] Хостинг или сервер: где разворачиваем
