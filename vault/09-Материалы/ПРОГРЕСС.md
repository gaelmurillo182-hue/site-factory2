## Что где лежит

```
brief/ai-agency-kb/       ← ресёрч, рубрикация, продукты, продажи, итерации, снимки QA
brief/ai-agency-kb-site.md ← бриф на публичный сайт агентства
vault/                     ← Obsidian-хранилище, 143 заметки. Источник правды по контенту
sites/ai-agency-kb/        ← приложение
scripts/seed-vault.mjs     ← разовый посев vault из данных (существующее не перезаписывает)
scripts/vault-seed/        ← данные посева
scripts/qa-kb.mjs          ← визуальный QA: снимки 390 и 1920, контраст, ошибки консоли
scripts/qa-questions.mjs   ← проверка пользы: 15 рабочих вопросов через ассистента
```

## Как запустить

```bash
cd sites/ai-agency-kb && npm run dev
```

Сборка данных из vault идёт автоматически перед `dev` и `build`.
Правите заметку в Obsidian → перезапускаете → приложение видит изменения.

## Как проверить после правок

```bash
node scripts/qa-kb.mjs http://localhost:5183/
```

```bash
node scripts/qa-questions.mjs http://localhost:5183/
```

## Не сделано намеренно

- Публичный сайт агентства не сверстан — на него написан бриф, это отдельный заказ.
- Подключения LLM к ассистенту нет: поиск локальный, офлайновый, ничего не выдумывает.
