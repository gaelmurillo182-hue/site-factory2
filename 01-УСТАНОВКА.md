## Шаг 0. Что должно быть на компьютере

| Софт | Зачем | Проверка |
|---|---|---|
| **Node.js 20 LTS или новее** | нужен и Claude Code, и `npx skills`, и сборщику сайта | `node -v` |
| **npm** | ставится вместе с Node | `npm -v` |
| **Git** | клонирование репозиториев | `git --version` |
| **Claude Code** | сам агент | `claude --version` |

Установка Claude Code (официальная страница: <https://code.claude.com/docs>):

```bash
npm install -g @anthropic-ai/claude-code
```

> ⚠️ Требования к версии Node у Claude Code иногда меняются. Если `npm install` ругается —
> сверьтесь с <https://code.claude.com/docs>, это единственный источник, который не устаревает.

Первый запуск и вход в аккаунт:

```bash
claude
```

Дальше — авторизация в браузере. Нужен платный план (Pro / Max) или API-ключ.

## Шаг 1. Распакуйте этот проект

Положите папку `site-factory` куда-нибудь в рабочую директорию, например:

- Windows: `C:\work\site-factory`
- macOS/Linux: `~/work/site-factory`

```bash
cd ~/work/site-factory
```

Структура, которая у вас уже есть:

```
site-factory/
├── CLAUDE.md                 ← правила проекта, Claude читает автоматически
├── .mcp.json                 ← подключение Playwright (глаза агента)
├── .claude/
│   ├── agents/               ← 6 субагентов
│   └── commands/             ← 4 слэш-команды
├── brief/
│   ├── TEMPLATE.md           ← шаблон брифа
│   └── ПРИМЕР-lavitek.md     ← заполненный пример
└── docs/                     ← эти инструкции
```

## Шаг 2. Поставьте скиллы

### 2.1. Базовый набор (обязательный минимум — 4 скилла)

Философия проверенного источника (novitckii.com): **не ставьте все 42**. Ставьте
четыре слоя — вкус, движение, токены, глаза. Остальное добавляйте по потребности.

Выполните **в корне `site-factory`**:

```bash
# 1. ВКУС — база. Anthropic frontend-design
npx skills add anthropics/skills --skill frontend-design

# 2. ВКУС+ — taste-skill v2 (три «ручки»: variance / motion / density)
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

# 3. ТОКЕНЫ — цветовые/типографские системы вместо случайных hex
npx skills add anthropics/skills --skill theme-factory

# 4. ДВИЖЕНИЕ — правила анимации Эмиля Ковальски
npx skills add https://github.com/delphi-ai/animate-skill --skill animate
```

### 2.2. Для редизайна существующих сайтов

```bash
# аудит существующего кода → починка вёрстки
npx skills add https://github.com/Leonxlnx/taste-skill --skill "redesign-existing-projects"

# скриншот/референс → анализ → код
npx skills add https://github.com/Leonxlnx/taste-skill --skill "image-to-code"

# извлечение «Design DNA» из чужого сайта в JSON-токены
npx skills add zanwei/design-dna
```

### 2.3. Анимация и 3D (по желанию)

```bash
# официальные скиллы GSAP (8 штук: core, timeline, scrolltrigger, react, plugins…)
npx skills add https://github.com/greensock/gsap-skills

# принципы движения от LottieFiles
npx skills add LottieFiles/motion-design-skill

# аудитор анимации: ловит scale(0), голый ease, отсутствие reduced-motion
npx skills add kylezantos/design-motion-principles
```

### 2.5. Impeccable — отдельный установщик

```bash
npx impeccable install
```

Потом внутри Claude Code:

```
/impeccable init
```

Он создаст `PRODUCT.md` и предложит `DESIGN.md` — это долговременная память о бренде.
Дальше доступны 23 однословные команды: `polish`, `audit`, `critique`, `bolder`, `quieter`, `animate`.

> **Не ставьте одновременно** `frontend-design` + `impeccable` + `design-taste-frontend`
> и не активируйте их в одном запросе. Это три конкурирующих «слоя вкуса», они спорят
> друг с другом. Выберите один основной, остальные держите как запасные.

## Шаг 3. Дайте агенту глаза — Playwright MCP

Это самый важный пункт всей установки. Без него модель верстает вслепую.

```bash
claude mcp add playwright -s user -- npx @playwright/mcp@latest
```

Проверка — внутри `claude`:

```
/mcp
```

В списке должен появиться `playwright` со статусом «connected».

Что это даёт: агент сам открывает свою страницу в браузере, делает скриншоты на
1920px и 390px, сравнивает с референсом и правит CSS, пока не совпадёт. Это
превращает одноразовую генерацию в цикл «сделал → посмотрел → исправил».

## Шаг 5. Проверка сборки

```bash
cd ~/work/site-factory
claude
```

Внутри Claude Code:

```
/agents          → должны быть видны 6 наших агентов
/mcp             → playwright: connected
/help            → в списке /new-site, /redesign, /polish, /brief
```

Если `/new-site` не видно — проверьте, что вы запустили `claude` **из корня
`site-factory`**, а не из домашней папки. Команды в `.claude/commands/` работают
только в своём проекте.

## Что я НЕ проверял (честно)

1. **Качество и безопасность содержимого скиллов.** Я подтвердил, что репозитории
   существуют и содержат `SKILL.md` с указанными именами. Я не читал каждый скилл
   построчно. Скиллы могут выполнять код в вашей среде — репозитории от
   Anthropic, Microsoft, GreenSock и LottieFiles это организации с именем;
   остальные — работа частных лиц. Перед установкой имеет смысл открыть
   `SKILL.md` глазами.

2. **Звёзды на GitHub.** В обзорных статьях фигурируют цифры вроде «44k звёзд у
   impeccable» и «59.4k у taste-skill». Я не смог их подтвердить — GitHub API
   отдал rate limit. Считайте эти числа непроверенными.

3. **Работоспособность конкретных install-команд на вашей машине.** Команды взяты
   из README самих репозиториев (это первоисточник), но я их не запускал.

4. **Расхождение по `theme-factory`.** Статья-источник приписывает его Composio
   (`ComposioHQ/awesome-codex-skills`). Я проверил напрямую: файл
   `skills/theme-factory/SKILL.md` лежит **в `anthropics/skills`**. В инструкции
   выше указан именно проверенный вариант.

5. **`CloudAI-X/threejs-skills`.** Репозиторий существует и содержит 10 скиллов,
   но в его README раздел установки ссылается на **другой** репозиторий
   (`pinkforest/threejs-playground`). Это несоответствие внутри самого репозитория,
   не моя опечатка. Ставьте через `git clone`, а не по README.

6. **Пункты 19–22 из списка «42 навыка»** (Hi-fi mockups, Design systems,
   Templates, Slide decks) — это **не репозитории**. Это функции веб-продукта
   Claude Design на <https://claude.ai/design>. Локально не устанавливаются.
