# Разбор результатов и работа над ошибками

## Обязательный порядок

### 1. Найти открытые ставки

```bash
cd betting/engine && python3 -m sbr journal open --db ../journal/bets.db
```

### 2. Найти реальные результаты

Только по источникам — `football-data`, `nhl-data`, `nba-data`,
`sports-news` и т.д. **Результат, который не подтверждён источником, не
проставляется.** Лучше оставить ставку открытой, чем записать выдуманный счёт.

### 3. Проставить результат И закрывающий коэффициент

```bash
python3 -m sbr journal settle <id> won --closing 1.85 --detail "2:1" --db ../journal/bets.db
```

Статусы: `won` `lost` `push` `void` `half_won` `half_lost`.

**Closing odds — обязательное поле.** Без него не считается CLV, а CLV — самая
ранняя честная метрика качества: она работает задолго до того, как ROI
перестанет быть шумом.

### 4. Отчёт

```bash
python3 -m sbr journal report --db ../journal/bets.db
python3 -m sbr journal report --segment market --db ../journal/bets.db
python3 -m sbr journal report --segment odds_band --db ../journal/bets.db
python3 -m sbr journal report --include-shadow --db ../journal/bets.db
```

## Как читать цифры — и чего не делать

**Порядок важности: CLV → калибровка → Brier → ROI → win rate.**
Win rate последний, потому что он механически зависит от кэфов.

| Закрытых ставок | Что можно утверждать |
|---|---|
| < 30 | ничего. Это шум. Так и сказать пользователю. |
| 30–50 | предварительные наблюдения, гипотезы |
| 50–100 | можно искать слабые сегменты |
| 100+ | можно менять веса факторов |

**Запрещено менять модель после 2–3 проигранных ставок.** Это подгонка под
шум, и она ухудшает модель. Если пользователь просит — объяснить почему нет.

### Калибровка

Если ставки с P_model 60% заходят примерно в 60% — модель откалибрована.
Систематический разрыв вверх — underconfidence, вниз — overconfidence.
Overconfidence опаснее: на завышенных вероятностях считается размер ставки.

### Shadow-портфель

Сравнить, как отработали отклонённые идеи. Если отклонённые в плюсе на
приличной выборке — фильтры слишком строгие. Если в минусе — фильтры работают,
и это главный аргумент их не ослаблять в плохую неделю.

## Самоаудит (каждые 25–30 закрытых ставок)

Ответить письменно: что работает; что нет; какие рынки дают CLV+; какие CLV−;
есть ли overconfidence; есть ли underconfidence; какие источники чаще помогают;
какие Reason Codes прибыльны; какие фильтры усилить; какие факторы переоценены.

Записать вывод в `betting/journal/SELF_AUDIT.md` с датой, числом ставок и
версией модели. Изменение модели повышает версию (V5.0 → V5.1), и результаты
разных версий не смешиваются.
