## Что делать

### 1. Посмотреть
`visual-qa` через Playwright: 390px и 1920px. Без этого шага полировка вслепую.

### 2. Найти признаки «сделано нейросетью»

Проверь по списку и выпиши **конкретные файлы и строки**:

- [ ] Inter / Roboto / Open Sans / Montserrat / Poppins как основной шрифт
- [ ] Градиент фиолетовый → синий; цвета `#6366f1`, `#8b5cf6`, `#a855f7`
- [ ] Ряд из четырёх одинаковых карточек как решение раздела
- [ ] Скруглённая иконка в квадратике над каждым заголовком
- [ ] Карточка внутри карточки
- [ ] Серый текст на цветном фоне
- [ ] Захардкоженные цвета и отступы вместо токенов
- [ ] Отступы не кратны шагу сетки
- [ ] Строка длиннее 75 символов в основном тексте
- [ ] Все веса шрифта одинаковые — нет иерархии
- [ ] Hover без transition
- [ ] Анимация `width` / `height` / `top` / `left`
- [ ] Нет `prefers-reduced-motion`
- [ ] Остатки `lorem ipsum` или выдуманных цифр

### 3. Починить
По приоритету: ломающее → заметное → мелочи.
Каждая правка — через токены, а не хардкодом.

### 4. Перепроверить
`visual-qa` повторно. Скриншоты до/после.

## Если стоит Impeccable

Можно прогнать его команды вместо ручного чек-листа:
```
/impeccable audit
/impeccable polish
```
Но скриншот-проверку через Playwright всё равно сделай — Impeccable
анализирует код, а не отрендеренную страницу.
