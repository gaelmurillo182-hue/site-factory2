# Источники данных

## Что установлено в проекте

`machina-sports/sports-skills` — 26 скиллов, без API-ключей, в `.claude/skills/`:

| Скилл | Покрытие | Данные |
|---|---|---|
| `football-data` | АПЛ, Ла Лига, Бундеслига, Серия А, Лига 1, РПЛ, ЛЧ, ЛЕ, MLS и др. | таблицы, календарь, статистика матчей, **xG**, трансферы, травмы, H2H, Elo, прогнозы |
| `nhl-data` | **только NHL** | счета, таблицы, составы, вратари, травмы, play-by-play с координатами, лидеры |
| `nba-data` / `wnba-data` / `cbb-data` | НБА, ВНБА, NCAA | + продвинутые рейтинги, shot charts |
| `mlb-data` | MLB | + скорость подачи, spin, exit velocity |
| `nfl-data` / `cfb-data` | NFL, NCAA | + play-by-play через nflverse |
| `tennis-data`, `golf-data`, `cricket-data`, `volleyball-data`, `fastf1`, `esports` | теннис, гольф, крикет, волейбол, F1, Dota/LoL | базовая статистика |
| `sports-news` | все | новости, травмы |
| `polymarket`, `kalshi`, `markets` | прогнозные рынки | цены как независимый рыночный ориентир |
| `betting` | — | конвертация кэфов, девиг, Kelly, арбитраж |
| `metadata` | 100+ лиг | логотипы, стадионы, профили |

Установка на другой машине:

```bash
npx -y skills add machina-sports/sports-skills --skill '*' --agent claude-code -y --copy
pip3 install sports-skills numpy scipy
```

## Чего нет и что с этим делать

**КХЛ не покрыта.** `nhl-data` прямо оговаривает, что другие хоккейные лиги
(КХЛ, АХЛ, студенческий) не поддерживаются. По КХЛ — официальный сайт лиги,
сайты клубов, профильные СМИ, вручную. Это напрямую бьёт по Data Quality:
без подтверждённого вратаря компонент `lineup_goalie_certainty` низкий, и
VALUE по вратарезависимым рынкам запрещается автоматически.

**Коэффициентов букмекеров нет ни в одном из этих скиллов.** Prediction
markets (Polymarket, Kalshi) — это ориентир, а не линия Fonbet. Линию
присылает пользователь текстом.

**Платные API кэфов**, если понадобится автоматизация (цены на 2026):
The Odds API — бесплатно 500 кредитов/мес, но бесплатный тариф только NBA+MLB;
OddsPapi — 250 запросов/мес, 350+ контор в одном ответе; Odds-API.io —
бесплатно 100 запросов/час. Футбольная статистика: API-Football (бесплатно
100 запросов/сутки, все лиги), Sportmonks (от €29/мес), Football-Data.org.

## Ограничение этого окружения

Контейнер, в котором собирался проект, закрыт egress-политикой: запросы к
`api-web.nhle.com`, `site.api.espn.com`, `api.the-odds-api.com`,
`understat.com`, `moneypuck.com`, `api.football-data.org`, `khl.ru`,
`fbref.com` получают 403 на CONNECT. Проверено прямыми запросами;
отказы видны в `curl -sS "$HTTPS_PROXY/__agentproxy/status"`.

Практический вывод: **скиллы данных работают на вашей машине, но не внутри
этой сессии.** Движок, парсер, журнал и математика от сети не зависят и
работают везде.

## Приоритет источников при конфликте

1. официальная лига → 2. официальный клуб → 3. официальный injury/lineup
report → 4. надёжная статбаза → 5. beat reporter → 6. крупное СМИ →
7. агрегатор → 8. стороннее preview.

Для кадровых фактов — минимум два подтверждения либо официальный источник.
VALUE на одном preview-сайте не строится.
