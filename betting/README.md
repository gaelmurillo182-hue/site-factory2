# Betting Research System V5

Исследовательская система по букмекерским рынкам: считает вероятности,
сравнивает их с ценой, применяет жёсткие фильтры, распределяет банк и ведёт
журнал с разбором ошибок.

**Это калькулятор и бухгалтер, а не оракул.** Система не предсказывает
результаты. Она оценивает вероятности и цены, и по построению часть этих
оценок будет неверной. Положительное EV — утверждение о среднем на большой
дистанции, а не обещание выигрыша.

## Установка

```bash
pip3 install numpy scipy sports-skills
npx -y skills add machina-sports/sports-skills --skill '*' --agent claude-code -y --copy
cd betting/engine && python3 -m pytest tests/ -q
```

## Использование

В Claude Code: `/scan <линия текстом>` и `/audit`.

Вручную:

```bash
cd betting/engine
python3 -m sbr parse   ../scans/2026-09-18/line.txt
python3 -m sbr devig   --odds 1.95,3.60,4.20
python3 -m sbr scan    ../scans/2026-09-18/input.json --out ../scans/2026-09-18/report.md --journal
python3 -m sbr journal report --segment odds_band
```

## Правила банка (100 000 ₽)

1U = 1 000 ₽ (1%). Лимит сессии — 5U = 5 000 ₽ **на все ставки вместе**.
Резерв под WAIT/live — 1.5U. Потолок одной ставки 1.5U, кластера — 2U.
Четвертной Келли. Размер ставки никогда не зависит от результата предыдущей.

## Ответственная игра

Ставки — не источник дохода и не способ отыграться. Ставьте только те деньги,
потерю которых можете спокойно пережить. Если ставки перестали быть
добровольными — это повод остановиться, а не увеличить банк.
