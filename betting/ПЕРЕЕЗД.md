## 1. Забрать код

```bash
git clone https://github.com/gaelmurillo182-hue/site-factory2
cd site-factory2
git checkout claude/intelligent-sagan-ujuape
```

старая студия сайтов, к этому проекту отношения не имеет.

## 3. Восстановить журнал

База `journal/bets.db` намеренно не в git — она бинарная. Переносится CSV:

```bash
cd betting/engine
python3 - <<'PY'
import csv, sys; sys.path.insert(0,'.')
from sbr.journal import Journal, Bet
j = Journal("../journal/bets.db")
with open("../journal/bets.csv", encoding="utf-8") as fh:
    for r in csv.DictReader(fh):
        b = Bet(scan_date=r["scan_date"], match=r["match"], market=r["market"],
                selection=r["selection"], odds_taken=float(r["odds_taken"]),
                verdict=r["verdict"], sport=r["sport"] or None,
                units=float(r["units"] or 0), stake=float(r["stake"] or 0),
                p_market=float(r["p_market"]) if r["p_market"] else None,
                p_model=float(r["p_model"]) if r["p_model"] else None,
                is_shadow=r["is_shadow"] == "1")
        i = j.add(b)
        if r["status"] != "open":
            j.settle(i, r["status"], r["result_detail"] or None,
                     float(r["closing_odds"]) if r["closing_odds"] else None)
j.close(); print("журнал восстановлен")
PY
```

## 4. Что изменится, когда сеть откроется

Это главное. В облачном контейнере egress-политика резала всё спортивное:
`fbref.com`, `understat.com`, `api-web.nhle.com`, `site.api.espn.com`,
`fon.bet`, `skills.sh` — все отдавали 403 на CONNECT. У вас они откроются,
и заработает то, что здесь простаивало:

| Заработает | Что это даёт |
|---|---|
| 26 скиллов `machina-sports` | xG, составы, травмы, вратари — автоматически, а не через веб-поиск |
| `fit_dixon_coles` | **рейтинги команд из результатов**; λ считается, а не ставится руками |
| `npx skills find` | поиск скиллов (ходит в GitHub API, здесь был закрыт) |
| Pinnacle / сравнение контор | эталонная цена вместо сравнения Fonbet с самим собой |

**Первое, что стоит сделать локально** — скормить подгонщику результаты одной
лиги за сезон. Тогда λ перестанут быть моим суждением. Как это выглядит:

```python
from sbr.football import MatchResult, fit_dixon_coles
matches = [MatchResult("Порту","Бенфика", 2, 1, days_ago=3), ...]
fit = fit_dixon_coles(matches, half_life_days=120)
lh, la = fit.lambdas("Порту", "Спортинг")
```

## 5. Незакрытые дела

**Четыре ставки от 20.09 висят открытыми** — их надо рассчитать:

```bash
python3 -m sbr journal open --db ../journal/bets.db
python3 -m sbr journal settle <id> won --closing <кэф> --db ../journal/bets.db
```

Closing odds обязательны, без них не считается CLV.

**Что ещё не сделано в проекте** (честный список, не «дорожная карта»):
- нет кода под xG, xGA, PPDA, силу календаря, стандарты, HDCF/Corsi —
  всё это перечислено в мастер-промпте, но не реализовано;
- `fit_dixon_coles` покрыт тестами, но ни разу не работал на реальных данных;
- коэффициент неуверенности 0.25 взят из литературы, а не откалиброван
  на нашей выборке — проверять по журналу после 50+ закрытых ставок.
