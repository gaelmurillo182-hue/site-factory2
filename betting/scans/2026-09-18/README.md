# Скан на 18.09.2026 — статус: ЖДЁТ ЛИНИЮ

## Почему скана здесь пока нет

Скан невозможен без двух вещей, ни одной из которых у системы нет:

**1. Линии.** Метод целиком состоит из сравнения модели с ценой. Без
коэффициентов Fonbet нет ни `P_market`, ни edge, ни EV, ни размера ставки.
Линия не была прислана.

**2. Доступа к данным.** Контейнер, в котором собиралась система, закрыт
egress-политикой: `api-web.nhle.com`, `site.api.espn.com`,
`api.the-odds-api.com`, `understat.com`, `moneypuck.com`,
`api.football-data.org`, `khl.ru`, `fbref.com` — все отвечают 403 на CONNECT.
Проверено прямыми запросами, отказы видны в
`curl -sS "$HTTPS_PROXY/__agentproxy/status"`.

Придумать вместо этого составы, xG, вратарей и коэффициенты означало бы
нарушить первое правило регламента. Пустой скан честнее выдуманного.

  2026 ([khl.ru](https://www.khl.ru/calendar/)). Конкретные пары на 18.09
  подтвердить не удалось — сайт лиги из этого окружения недоступен.
- **НХЛ 18.09.2026 не играет вообще.** Предсезонка сезона 2026/27 начинается
  в субботу 19 сентября и идёт по 26 сентября, регулярный чемпионат стартует

- 18.09.2026 — пятница, то есть в европейских лигах это стартовый день тура.

Ничего из этого не является основанием для ставки. Это только контекст.

**Отдельное предупреждение по НХЛ на ближайшие дни.** Когда 19–26 сентября
предсезонка всё-таки начнётся, ставить по ней по этой системе почти наверняка
не получится, и это не сбой: составы неизвестны до последнего часа, вратари
делят матч пополам, ведущие игроки проводят по половине игры. Это значит
низкую `lineup_goalie_certainty`, низкую Data Quality и автоматический запрет
VALUE. Предсезонные матчи — ровно тот случай, ради которого шлагбаум
`DQ < 60 → VALUE запрещён` и существует.

## Что нужно, чтобы скан появился

Пришлите линию текстом — в любом виде, как копируется из приложения:

```
КХЛ
18.09 19:30 Ак Барс - Авангард
П1 2.10 X 4.20 П2 2.90
Ф1(-1.5) 3.60 Ф2(+1.5) 1.32
ТБ 5.5 1.95 ТМ 5.5 1.90
Победа Ак Барс в основное время 2.55

РПЛ
18.09 21:00 Спартак - ЦСКА
П1 2.05 X 3.50 П2 3.60
Тотал больше 2.5 - 1.92 Тотал меньше 2.5 - 1.88
ОЗ да 1.80 ОЗ нет 1.98
```

Важно: **в каждом рынке нужны все исходы.** Одна цена без остальных не даёт
снять маржу, и такой рынок уйдёт в REJECTED с этой причиной.

Дальше достаточно написать `/scan` — либо руками:

```bash
cd betting/engine
python3 -m sbr parse ../scans/2026-09-18/line.txt
# заполнить input.json по docs/WORKFLOW.md
python3 -m sbr scan ../scans/2026-09-18/input.json \
  --out ../scans/2026-09-18/report.md --journal --db ../journal/bets.db
```

## Разделение «день» и «ночь»

День и ночь — это две отдельные сессии, и лимит 5U считается **для каждой
отдельно**, но только если между ними вы реально подводите итог. Если ставки
дня ещё не сыграли, когда открываются ночные, экспозиция суммируется, и
общий лимит на открытые позиции остаётся 5U = 5 000 ₽.

Практично: `scans/2026-09-18-day/` и `scans/2026-09-18-night/` с
`max_session_units: 2.5` в каждом — тогда суммарная открытая экспозиция
не превысит 5U ни при каком стечении обстоятельств.
