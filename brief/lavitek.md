## 3. Подтверждённые факты о продукте

Всё, что можно писать на сайте без оговорок:

- срок изготовления — **от 14 дней**;
- точность — **до 0,01 мм**;
- работа по **ГОСТ и ISO**;
- изготовление **по чертежам заказчика**;
- **прямой импорт** из Китая.

Числа, которые были на старом сайте и **на новый не переносятся** без
подтверждения: «7 проверенных заводов», «6+ фабрик», «полный цикл от добычи
сырья», «собственные фабрики».

## 4. Номенклатура, подтверждённая каталогами клиента

Волочильный инструмент — это то, по чему у клиента есть размерные ряды
и обозначения: волоки и фильеры (ряд `1010-XXXX`), заготовки волок (ряд
`1980-XXXX`), волоки для мокрого волочения (GT01), для проволоки и прутка
(GS11, GS2, GV, GW), для труб (G22, G23), прессовые матрицы (GY01), профильные
модельные заготовки (GP01), трубные оправки, комплектующие.

Марки сплава из каталога с характеристиками: серии GK (GK05, GK05A, GK05C,
GK10H, GK10X, GK30H), GU (GU10, GU20, GU10UF), GF (GF40H, GF50H) — с HRA,
плотностью, пределом прочности при изгибе и размером зерна.

Полное дерево каталога с пометками об источнике — `sites/lavitek/КАТАЛОГ.md`.

на руках чертёж и задача найти, кто это сделает. Он не «изучает бренд». Он
проверяет, разговаривают ли здесь на его языке.

## 7. Задачи сайта

1. Принести органический трафик по всей России — экспертными страницами
   (марки, соответствия, допуски, НТД), а не подделкой региональных страниц.
2. Дать технологу повод отправить чертёж: понятно, что прислать и что будет дальше.
3. Снять главное возражение прямого импорта из Китая — разброс от партии к партии.
4. Заменить одностраничник на структуру, где у каждого направления свой URL.

## 8. Технические требования

- Vite + React 19 + TypeScript + Tailwind v4 (стандарт студии).
- Предрендер всех маршрутов в статику через Playwright — SPA-выдача недопустима.
- Перенести: счётчик Метрики 6503185, `yandex-verification 3e6e0dd122c9b401`,
  `msvalidate.01 C4AF80FCE4A4BDA4A97DCDBCA94995A5`.
- Сохранить существующие URL: `/uslugi`, `/otrasli`, `/o-nas`,
  `/preimushchestva`, `/kontakty`.
- LCP < 2,5 с, CLS < 0,1. Шрифты self-host, изображения WebP с размерами.
- Форма: чекбокс согласия + ссылка-заглушка на политику ПДн.
